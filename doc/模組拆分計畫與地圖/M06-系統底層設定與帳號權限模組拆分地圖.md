## 一、架構整合與消滅重複項目（已落實）

1. **合併跨檔案雙胞胎元件與公用工具**：
   - **公司出款銀行專戶 CRUD + Modal (`CompanyBankAccountModal.tsx`)**：將原分散於 `BasicSettingsHubWorkspace`（支票簿設定）與 `CompanySettingsWorkspace`（法人出款專戶）的重複彈窗合併為共用元件，並內嵌既有 `TaiwanBankPickerWidget` 台灣金融機構代碼選取器。
   - **台灣統編／身分證／Email 共用校驗 (`src/utils/taiwanValidation.ts`)**：擴充支援性別判斷回傳與 `validateEmail`，移除 `CompanySettingsWorkspace` 內原本重複手寫之演算法，改由 `CompanyEntityFormPanel` 統一調用。
   - **台灣縣市郵遞區號地址選擇器 (`TaiwanAddressPicker.tsx`)**：於 `CompanyEntityFormPanel` 中採用 `<TaiwanAddressPicker compact />` 處理「登記地址」與「聯絡通訊地址」，前段選單與後段門牌號自動組裝回寫 `fullAddress`。
   - **SQLite 備份還原共用引擎與拖曳區 (`sqliteBackupUtils.ts` + `DatabaseRestoreDropzoneCard.tsx`)**：統一 `.sqlite`/`.db`/`.sql` 匯出下載、格式檢查與覆蓋還原流程，同時服務 `DatabaseManagementModal` 與 `SettingsDatabaseHubTab`。
   - **全系統軟刪除註冊表機制 (`softDeleteRegistry.ts` + `RecoveryEntityTable.tsx`)**：以註冊表模式收斂多實體兩階段軟刪除（軟刪除欄位隱藏 ➔ 救援還原 ➔ 不可逆物理抹除），並於 `SuperadminRecoveryCenterModal` 擴充納入 `COMPANIES`（公司法人／老闆私帳）為第 5 個救援分頁。
2. **全面消滅 iFrame 安全地雷**：
   - 徹底清除 `BasicSettingsHubWorkspace` 與 `DatabaseManagementModal` 內剩餘之 4 處 `window.confirm`，全面接軌共用防呆元件 `ConfirmDialogModal`。經靜態掃描確認 M06 全目錄 0 處原生 `window.confirm`／`window.alert`。
